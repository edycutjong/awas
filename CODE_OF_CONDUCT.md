# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good faith, and keep discussion about the work. Awas deals with real recruitment scams that harm
real people: never post victims' personal data, phone numbers or identifying details.

Report conduct problems by opening a private security advisory on this repository (Security tab → Report a vulnerability)
or by contacting the maintainer, @edycutjong, through their GitHub profile.
