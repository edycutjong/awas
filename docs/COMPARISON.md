## Where Awas differs

- **Awas gives no score and has no safe state.** It returns STOP, VERIFY FIRST or NO RED FLAGS FOUND. These tools return a score or a safe label (ScamAdviser, Scamio, Whoscall, JobScamScore, Verifin, CekLoker AI). ScamAdviser's top level is "Very Likely Safe" [3b]. Scamio "lets you know if it’s safe or not" [4b]. Whoscall flags "what's safe, suspicious, or dangerous" [7a]. JobScamScore returns "A 0–100 risk score" [15b]. Verifin's verdicts include "AMAN" [16b]. CekLoker AI returns a score of "0–100" [17b].
- **Awas reads the pasted offer, then checks the company it names against a dated snapshot of the P3MI list** (SISKOP2MI, KP2MI Migran Aman). On SISKOP2MI a person types a name into the P3MI list and reads the row [10a], [10b]. The Migran Aman page sends people to that list and to the vacancy board [13b], [13c]. Neither page says it accepts a pasted offer. A snapshot can be older than the live list, so SISKOP2MI stays the source.
- **Awas applies red-flag rules quoted from official Indonesian government pages** (Scamio, Norton Genie, Whoscall, JobScamScore, Verifin, CekLoker AI, Karir Fair). The pages read for these tools do not mention P3MI or sending Indonesian workers abroad. Scamio mentions "job scam" [4f]. CekLoker AI lists patterns for vacancies "di Indonesia" [17d].
- **Awas shows an evidence line only if its quote is found in the page text, and each quote links to its source** (Norton Genie, JobScamScore, Verifin). Norton's FAQ says Genie gives "why it made that assessment" [5c]. JobScamScore says "Every red flag explained" [15d]. Verifin says "Evidence Attribution menunjukkan kontribusi tiap sinyal" [16b]. None of the three pages says a quoted sentence is matched against the source text, or that a quote links to its source. In Awas this is checked in code. The quote must appear verbatim in the page text the search returned. Each quote links to the source page with the sentence highlighted.
