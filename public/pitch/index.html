The model looks. Code decides.

Three Nemotron calls on Nebius Token Factory. Tavily finds the pages. Code decides what is shown and what the verdict is.

Nemotron 3 Super extracts typed fields with spans, then proposes quotes over the pages Tavily returned, then writes the Bahasa family message.

The rules, the quote gate and the verdict are plain code. The evidence pack is stored in Nebius Object Storage with a case id.

This is the mechanism. The model may propose a quote that flips one clause — the negation that changes everything. The gate drops it on screen.

Only the verbatim sentence gets the highlighter, and its link opens the official page with that sentence marked. Judges can try to fool it on the landing page.
