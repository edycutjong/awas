Nemotron 3 Ultra reads the offer into typed fields; code checks every field is really in the text. Sixteen rules in code decide — fourteen quote official pages, two check a dated snapshot of the licensed-agency (P3MI) list. Tavily finds context; Nemotron 3 Super proposes quotes; a code gate keeps only quotes found word for word; a truth table sets the verdict. The verdict is decided in code on purpose, so that a model cannot stamp STOP by itself; in the benchmark Nemotron's measured effect on the STOP count is one evidence-flipped case, and it also supplies the typed fields, the evidence lines and the family message.
